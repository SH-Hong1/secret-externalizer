# EUC-KR 파일에서 원본 폴더 실행이 버린 결과는 세지 않기

- 날짜: 2026-11-26
- 상태: 확정

## 배경

EUC-KR 파일이 있는 스캔은 스캐너를 프로젝트 폴더와 UTF-8 사본 폴더에서 한 번씩 돌린다. EUC-KR 파일의 결과는 사본 폴더 실행에서만 쓰고, 프로젝트 폴더 실행의 결과는 EUC-KR 바이트 위치라 쓰지 않으며 버림 수에도 넣지 않는다. 그런데 프로젝트 폴더 실행에서 스캐너가 EUC-KR 파일의 결과를 스스로 버리면(값이 스캐너가 맞았다고 한 글 안에 없을 때), 그 파일의 주변 줄을 모두 빼고 버림 수에 더했다(#122). 쓰지 않을 결과가 버려졌을 뿐인데 사본 폴더에서 제대로 찾은 항목까지 주변 줄을 잃었다.

## 결정

1. 프로젝트 폴더 실행이 EUC-KR로 읽은 파일에서 버린 결과는 버림 수에 넣지 않고, 그 파일의 주변 줄도 빼지 않는다.
2. 사본 폴더 실행이 버린 결과, UTF-8 파일에서 버린 결과, 파일을 알 수 없는 버린 결과는 지금처럼 세고 주변 줄을 뺀다.

## 이유

- 프로젝트 폴더 실행의 결과를 그 파일에서 쓰지 않는다는 규칙(남긴 결과도 버림으로 세지 않는다)과 버린 결과를 같은 기준으로 다룬다.
- 버린 결과가 가리키는 값은 사본 폴더 실행이 같은 글을 UTF-8로 읽어 다시 판단한다. 거기서도 버리면 그때 주변 줄을 뺀다.
- 스캐너가 스스로 버리는 결과는 줄에서 찾은 결과뿐이고 파일 전체 결과(키 파일)는 버리지 않으므로, 파일 전체 결과를 프로젝트 폴더에서 받는 규칙과 부딪히지 않는다.

## 검토한 다른 방법

- 주변 줄만 남기고 버림 수에는 넣기: 쓰지 않는 결과가 리포트의 버림 수를 늘려, 같은 파일을 UTF-8로 저장했을 때와 수가 달라진다.
