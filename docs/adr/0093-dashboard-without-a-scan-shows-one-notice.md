# 성공한 스캔이 없는 대시보드는 안내 하나만 보인다

- 날짜: 2026-11-25
- 상태: 확정

## 배경

대시보드에서 필터의 프로젝트에 성공한 스캔이 하나도 없으면(`dashboard.Dashboard.Scanned`가 0) 타일과 추이 대신 "성공한 스캔이 없습니다. 프로젝트를 스캔하면 숫자가 보입니다."를 보이고, 분류별 남은 항목과 오탐이 많은 규칙 절도 보이지 않는다. 계획 7의 화면 문구는 타일과 차트만 안내로 바꾼다고 적었고, 두 절도 빠지는 것은 남은 일(이슈 #72)로 적혀 있었다.

## 결정

지금 동작을 유지한다. 성공한 스캔이 없으면 필터 양식, 안내 한 줄, 프로젝트 표만 보인다. 분류별 남은 항목과 오탐이 많은 규칙 절은 보이지 않는다. `TestHandleDashboard_NoScans`가 이것을 붙잡는다.

## 이유

- 두 절의 숫자는 성공한 스캔에서만 나온다. 분류별 수는 추이의 점(성공한 스캔)에서, 규칙 목록은 필터의 프로젝트마다 마지막 성공한 스캔에서 센다(`db.readRules`). 그래서 성공한 스캔이 없으면 두 절은 언제나 비어 있다.
- 비어 있는 절을 보이면 0인 막대 다섯 개와 "오탐으로 판정한 항목이 없습니다."가 나온다. 이것은 "남은 항목이 없다", "오탐이 없다"로 읽히지만 실제로는 아직 스캔하지 않았다는 뜻이다. 안내 한 줄이 그 사실을 바로 말한다.

## 검토한 다른 방법

- 두 절을 보이고 각 절에 "성공한 스캔이 없습니다"를 따로 적는다. 같은 안내가 세 번 나오고 알려 주는 것은 늘지 않는다.
- 두 절을 0인 그대로 보인다. 위의 이유로 잘못 읽힌다.
