# 대시보드 표의 마지막 스캔 시각은 끝난 시각이다

- 날짜: 2026-11-24
- 상태: 확정

## 배경

대시보드의 프로젝트 표는 마지막 스캔의 요청 시각을 보였고, 같은 화면의 추이 막대와 표는 끝난 시각을 보였다. 대기가 길었던 스캔은 두 시각이 18분까지 달랐다.

## 결정

표는 끝난 스캔이면 끝난 시각을, 아직 끝나지 않은 스캔(대기, 실행 중)이면 요청 시각을 보인다. 프로젝트 목록 화면은 바꾸지 않는다.

## 이유

한 화면의 시각이 같은 기준이어야 읽는 사람이 막대와 표를 맞춰 볼 수 있다. 끝나지 않은 스캔에는 끝난 시각이 없으므로 요청 시각이 남는다.

## 검토한 다른 방법

- 추이를 요청 시각으로 바꾼다: 추이의 순서가 (끝난 시각, ID)로 정해져 있어 맞지 않는다.
- 프로젝트 목록 화면도 바꾼다: 그 화면은 스캔의 상태 배지와 함께 요청을 보이는 곳이라 이번 범위에 넣지 않았다.
