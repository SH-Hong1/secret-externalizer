# 리포트 PDF는 별도 컨테이너에서 만든다

- 날짜: 2026-11-18
- 상태: 확정

## 배경

리포트의 주 독자는 개발자지만 공유를 위해 PDF 내보내기가 필요하다.

## 결정

- 헤드리스 브라우저 기반 변환 서비스(Gotenberg)를 별도 컨테이너로 둔다.
- web이 리포트 HTML을 완성해 pdf 컨테이너로 보내고 PDF를 돌려받는다.
- 리포트 HTML은 글꼴, 스타일, 차트를 모두 포함한 상태로 보낸다. pdf 컨테이너는 외부로 나가는 통신을 막고 web만 접근하게 한다.

## 이유

- 화면과 같은 템플릿에 인쇄용 스타일만 더해 쓰므로 화면과 PDF의 모양이 같다.
- pdf 컨테이너가 web에 접속해 페이지를 가져오게 하면 변환기에 로그인 세션을 줘야 한다. HTML을 보내는 방식은 그럴 필요가 없다.

## 검토한 다른 방법

- Go 라이브러리로 서버에서 직접 생성: 컨테이너가 늘지 않지만 화면과 모양이 달라지고 레이아웃을 따로 짜야 한다.
