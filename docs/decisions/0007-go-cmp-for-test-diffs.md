# 테스트의 구조체 비교에 go-cmp를 쓴다

- 날짜: 2026-11-18
- 상태: 확정

## 배경

`AGENTS.md`는 테스트에서 구조화된 값을 `cmp.Diff`로 비교하라고 정한다. 동시에 의존성은 표준 라이브러리로 할 수 없을 때만 추가하고 이유를 기록하라고 정한다.

## 결정

테스트 코드에서 `github.com/google/go-cmp`를 쓴다. 테스트가 아닌 코드에서는 쓰지 않는다.

## 이유

- `reflect.DeepEqual`은 같은지 다른지만 알려 준다. 스캔 결과처럼 필드가 많은 값이 다를 때 어느 필드가 다른지 실패 메시지에 나오지 않는다.
- `cmp.Diff`는 다른 부분만 보여 주므로 실패 메시지가 `AGENTS.md`의 "무엇을 돌려줬고 무엇을 원했는지" 규칙을 만족한다.
- 비교 방식을 옵션으로 조정할 수 있어, 시각이나 순서처럼 비교에서 빼야 할 필드를 테스트마다 손으로 지우지 않아도 된다.
- 테스트에서만 쓰므로 배포되는 바이너리에 들어가지 않는다.

## 검토한 다른 방법

- `reflect.DeepEqual`과 `%+v` 출력: 차이를 사람이 눈으로 찾아야 한다.
- testify 같은 단언 라이브러리: `AGENTS.md`가 단언 라이브러리를 금지한다. 실패 메시지를 직접 쓰는 방식과 맞지 않는다.
