# 결정 기록

나중에 읽는 사람이 "왜 이렇게 했는가"를 물을 만한 결정을 한 건당 파일 하나로 남긴다. 코드 주석에는 결정의 경위를 쓰지 않는다.

## 파일 이름

`NNNN-영문-요약.md`. `NNNN`은 0001부터 시작하는 4자리 순번이다.

## 본문 형식

```markdown
# 제목

- 날짜: YYYY-MM-DD
- 상태: 확정

## 배경

## 결정

## 이유

## 검토한 다른 방법
```

## 결정이 바뀔 때

기존 파일의 내용은 고치지 않는다. 새 파일을 만들어 새 결정을 쓰고, 기존 파일의 상태만 `대체됨 (NNNN 참조)`로 바꾼다.
