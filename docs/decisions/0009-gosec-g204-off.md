# gosec G204 규칙을 끈다

- 날짜: 2026-11-18
- 상태: 확정

## 배경

`AGENTS.md`의 Security 절은 외부 명령을 `exec.CommandContext`와 인자 슬라이스로 실행하라고 정한다. gosec의 G204는 인자가 상수가 아닌 `exec.CommandContext` 호출을 모두 지적한다. 스캐너 호출은 대상 경로가 인자로 들어가므로 항상 걸린다. 한편 `AGENTS.md`는 린트 지적을 억제하지 말고 고치라고 정한다.

## 결정

`.golangci.yml`에서 G204를 제외한다. 이 사실을 `AGENTS.md`의 "Formatting and tooling" 절에 적는다.

## 이유

- 규칙이 권하는 호출 형태를 린터가 지적하므로, 고칠 방법이 없는 지적이다.
- 호출마다 `//nolint:gosec`을 붙이면 같은 사유가 반복되고, 그 줄에서 gosec의 다른 규칙까지 함께 꺼진다.
- G204가 막으려는 위험은 셸을 거친 명령 실행과 검증하지 않은 입력이다. 셸 금지는 Security 절이 정하고, 입력 경로 검증도 같은 절이 정하며, 종료 시 검토가 이 절을 확인한다.

## 검토한 다른 방법

- 호출마다 `//nolint:gosec // 사유`: 위 이유로 제외.
- gosec 전체를 끄기: 다른 규칙(약한 난수, 파일 권한 등)은 계속 필요하다.
