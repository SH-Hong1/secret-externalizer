# 화면 시안

2026-11-19에 사용자가 확인한 시안이다. 화면을 구현할 때 이 문서의 값과 시안의 배치를 따른다.

- 시안(캔버스): https://claude.ai/artifact/JLGFEgXw6Dj5EUdj5gKbzC
- 이 폴더의 `*.dc.html`은 그 캔버스의 원본이다. 캔버스에서만 그려지고, 브라우저로 직접 열면 스타일 없이 보인다. 값은 모두 가짜다.
- 조직 기본 디자인 시스템은 쓰지 않는다. 이 도구만의 디자인이다.

## 시안과 다르게 구현하는 것

- **코드 글꼴은 D2Coding이다.** 시안은 IBM Plex Mono로 그렸다. 시안에서 `'IBM Plex Mono'`가 쓰인 자리는 모두 D2Coding으로 구현한다.

## 동작

- 판정 버튼(외부화, 삭제·마스킹, 오탐, 보류)은 누르면 바로 저장한다. 따로 저장 버튼을 두지 않는다. 보류는 옆의 사유 고르기 값을 함께 보낸다.
- 제안된 판정은 버튼에 "· 제안"을 붙이고 둘레 띠로 표시한다. 눌러야 저장된다.
- 이름 입력란은 접두어(`ext.` 또는 `EXT_`)를 입력란 앞에 고정해 보이고, 아래에 소스에 들어갈 모양을 보여 준다.
- 원본 값은 검은 테두리 상자 안에 보이고, 누가 언제 열었는지와 닫기 버튼이 함께 있다.
